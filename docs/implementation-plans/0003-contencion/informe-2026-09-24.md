## Lo que no se hizo, y por qué

Queda la comprobación de trazado de la 5.1, el canario (5.5.3) y la fase 7. Las tres lanzan
`claude -p`, y esta máquina no está preparada para ello. **No se lanzó ninguna sesión con modelo.**

| Falta | Comprobación | Consecuencia |
|---|---|---|
| Confianza del repo | `~/.claude.json` → `hasTrustDialogAccepted: false` | `claude -p` ignora el `allow` (E-6). El canario fallaría por la razón equivocada y el bucle no avanzaría |
| Plugin de Langfuse | no hay `~/.claude/state/`, ni el plugin en `~/.claude/plugins/cache`, ni `.claude/settings.local.json` | Sin trazas. CA-10 no se puede cerrar y RF-17 queda sin comprobar |
| `novela` en el PATH | `which novela` no lo encuentra; `~/.local/bin` no está en el PATH | Toda orden `novela` del bucle y de `ejecutar.py` falla (F-50) |
| `claude` en el PATH de Git Bash | solo existe `~/.local/bin/claude.exe` | El bucle y `ejecutar.py` no lo encuentran |

`uv` tampoco estaba instalado. Se instaló con `pip` en `Python312\Scripts`, que ya está en el PATH:
es el paso 1 de la puesta en marcha. `novela comprobar-entorno --limpio` sale con 0, porque no mira
la confianza ni el plugin.

Aceptar la confianza es decisión del operador (fase 6, paso 3), así que esta sesión no edita
`~/.claude.json`. La fase 7 necesita además dos cosas que solo puede hacer el operador: las claves
del plugin, que van al llavero del sistema, y `/memory` en una sesión interactiva.

## Para desbloquear

En este orden. Cada paso, con su comprobación de la fase 6.

1. `~/.local/bin` en el PATH de usuario, de forma persistente. Después, `uv tool install --editable ./backend`
   desde la raíz. Se comprueba con `novela --help` en una terminal nueva.
2. Abrir `claude` en la raíz del repo y aceptar el diálogo de confianza.
3. Instalar el plugin (`architecture.md` §10.1), con sus claves en el llavero, y habilitarlo en
   `.claude/settings.local.json` con `enabledPlugins`, sin nada más.
4. Tarea 5.1, paso 3: una sesión mínima con `--setting-sources project,local` y la traza en Langfuse.
5. Tarea 5.5.3: `cd backend && uv run python -m tests.canario.ejecutar`, con el árbol limpio.
6. Fase 7, desde la 7.1.
