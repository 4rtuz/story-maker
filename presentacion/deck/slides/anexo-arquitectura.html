Anexo A1 · Arquitectura

Quién hace qué, y por dónde pasa

Claude Code

Orquestador (slash commands), 9 subagentes en .claude/agents, skills del repo y memoria del proyecto.

Hooks

PreToolUse de policy (6 reglas, audit log) y PostToolUse que valida el capítulo en cuanto se escribe.

CLI novela

Python y Pydantic. Todo lo determinista: briefings, gates, story bible, Lean, guardrails, export y scores. Sin modelos.

Workspace

canon/ (verdad), plan/ (lo que debería pasar), estado.db (lo que pasó), memoria/, versiones/, qa/, runs/.

Lectura

API FastAPI de solo lectura, panel web y servidor MCP (5 tools de lectura y request_change con confirmación). LSP para la edición manual.

Observabilidad

Plugin de Langfuse (trazas y spans), scores del CLI, prompts versionados y Playwright MCP para la validación visual.
